## Delivered Contract

- Native source browsing defaults to a hierarchy with PATH/TYPE columns.
  `--tree`, `--flat`, `--chars`, node scoping and project-file discovery work.
- Native `source add` appends without reformatting authored bytes, preserves
  permissions, rejects duplicate aliases/generated-build edits, and supports
  dry-run. Adding a source neither fetches it nor selects its content.
- `source list|ls` lists declared locations without opening/fetching libraries;
  `--tree` browses their catalogs. Empty states explain local/Git addition.
- `source register` explicitly remembers a local checkout or Git URL;
  `source list --known` displays the user address book; `source add <name>` copies
  a remembered location into a project declaration.
- Terminal init uses optional external Gum for known/local/Git/skip choices.
  Preflight precedes prompting. Cancellation leaves no project file. Explicit
  sources, dry-run, nonterminal execution and --no-interactive bypass prompting.
- Gum was added to flake.nix and installed at ~/go/bin/gum v0.17.0 for the actual
  terminal smoke. No Go module dependency was added for Gum.

## Registry Format Recommendation

The owner asked whether YAML, TOML or the native language would fit. The agent
recommended and implemented YAML, matching existing user presentation config
and its existing parser dependency. This is an implementation recommendation
within the approved feature, not a claim that the owner separately selected YAML
after comparing full schemas.

The versioned registry is separate from display config, under the same
XDG/platform user configuration directory. It stores only alias/name/location.
Local paths are absolute; projects receive explicit relative locations or Git
declarations. Ordinary builds do not load the registry. Registration is explicit,
not ambient disk scanning or automatically registering every project source.
Remove/replace registry commands remain future convenience work.

and install passed for this exact follow-up; all changes remain uncommitted.
