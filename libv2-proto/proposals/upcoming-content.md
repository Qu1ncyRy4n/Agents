# Keep Useful New Content Separate from Corpus Coverage

These are candidates discovered during review, not claims that the protected
source guides already contain authoritative versions.

- Godot project and asset-graph practices, derived from future real dogfooding
  rather than a placeholder language module.
- A general architecture-law authoring pattern with tempting counterexamples.
- Cross-platform build and remote-execution guidance.
- A reusable external-service safety bundle covering credentials, rate limits,
  bounded live tests, retries, and partial failure.
- A delta-classification workflow for requested, concurrent, generated,
  unrelated, and conflicting changes.
- Library migration and compatibility rules for renamed source paths.
- Stable published-library identity, fork semantics, and cross-library
  relationship versioning.
- Authored import slots when exact in-document placement cannot be expressed
  cleanly by the manifest outline.
