# Intake

Status: draft, version 0.1.0.

Use this area for new source extraction before it is classified as an agent,
guide, skill, or specification candidate. Preserve source wording, provenance,
alternatives, and repository-local constraints. Each intake candidate must get
a `## Status` section and remain unselected until manually approved.

The reviewed candidate files currently live in the typed directories so QMR can
approve their intended destination directly. This is a review convenience, not
a promotion decision.
