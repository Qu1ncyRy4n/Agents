# Reproducible Analysis

Record the environment, input boundaries, transformations, output locations,
and known limitations for an analysis pipeline. Validate assumptions against the
task procedure before trusting downstream results. Keep raw data authoritative
and validate changes with fixtures or a safe copy when possible.
