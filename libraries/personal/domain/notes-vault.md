# Notes Vault

## Portability

Use valid Markdown first. Obsidian features such as YAML properties, wiki links,
callouts, embeds, aliases, and block identifiers are allowed when they add
value, but readers without Obsidian should still understand the file.

## Identity

Use time or explicit stable IDs for durable identity. Use tags for mutable
categorization and discovery, not as the only identifier for a session or
claim.

## Zettelkasten Style

Prefer small notes with clear titles, explicit links, and enough context to
stand alone. Preserve source/provenance distinctions between quotes, summaries,
personal claims, and unresolved questions.

## Flashcards

Keep flashcards focused on one recall target. Avoid turning every sentence into
a card. Preserve the surrounding note so cards remain connected to meaning.

## Agent Skills

Vault skills should state their trigger, input expectations, output format, and
where they are allowed to write. Avoid hidden mutation of notes outside the
requested scope.
